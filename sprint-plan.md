# Study Group Finder — Sprint Plan

## Sprint 1

**Goal:** Build a basic working version of the application that can be demonstrated to stakeholders.

- Set up the Flask application and MongoDB connection
- Create a basic mobile-friendly layout
- Allow students to browse available study sessions
- Allow students to view study session details
- Allow students to create a study session
- Allow students to search sessions by course or topic
- Add local setup and run instructions to the README

## Sprint 2

**Goal:** Complete the remaining CRUD operations, participation features, and business rules.

- Add user registration and login
- Allow students to join and leave a study session
- Allow organizers to edit session details
- Allow organizers to delete or cancel a study session
- Support both in-person and virtual sessions
- Enforce the maximum participant capacity
- Prevent students from joining the same session twice
- Detect scheduling conflicts
- Display session status: Waiting, Confirmed, Full, or Completed
- Test and improve the application
- Incorporate stakeholder feedback from Sprint 1
- Finalize the README and project documentation
